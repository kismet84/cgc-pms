## 4. 风险与回滚

- 监控认证不得以仓库静态 token、长期人工会话或扩大匿名 actuator 暴露实现。
- 测试 API 迁移只做等价注解替换；失败即逐文件回滚。
- 不为压低类行数创建无业务边界的服务或接口。
- `ssl.cnf` 未取得一次性运行证据前不删除；如后续删除导致 TLS 退化，立即恢复该文件并保持 `require_secure_transport`。
