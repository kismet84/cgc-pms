## 1. 范围与非目标

### 范围

- 明细表按 `yMm` 排序；首表以 `yMm` 建立流式起点，后表以设计矩形间距进入正常文档流。
- `heightMm` 是最小占位，不是动态内容上限；长表跨页并向后推后续流式表。
- 拒绝表格设计占位重叠，以及与同水平区域内、位于表格锚点之后的绝对 BODY 元素冲突。
- 版本 HTML 预览调用既有 `/document-templates/versions/{versionId}/preview-html`；保留服务端数据、权限和模板引擎边界。
- 修正第77条计划、质量报告、计划索引、当前焦点和项目地图的 Git 终态。

### 非目标

- 不把动态表格改为绝对定位，不截断动态行，不原地改写已发布或已停用历史版本。

## 2. 架构不变量与代码地图

- `design_schema` 是画布唯一持久事实；草稿保存时服务端编译并持久化 `template_content` 与 `field_manifest`。
- HTML 与 PDF 共用服务端编译、`RestrictedTemplateEngine` 与 OpenHTMLtoPDF；前端不解释模板占位符。
- 已发布版本不可变；历史版本不会因编译器升级自动重编译。
- `HEADER/FOOTER` 重复元素语义不变；BODY 绝对元素只允许位于流式表格锚点之前或水平不相交区域。
- iframe 保持 `sandbox=""`；无预览权限、失败、空结果或快速切换时不得回显 `templateContent` 或上一版本 HTML。

代码地图已在实施分支从当前树重新生成。调用、影响与测试答案：

- 调用：`DocumentTemplatePage/DocumentCanvas → system-management → DocumentTemplateController → DocumentTemplateService → DocumentCanvasCompiler/RestrictedTemplateEngine → OpenHTMLtoPDF`。
