# 第55条主线支线：业务编码自动编号治理任务计划书

**Goal:** 对当前 V2 业务域 30 个仍由人工录入的编码、编号或版本字段完成逐项事实分类，避免把外部/契约编号、版本语义和关系键误改为流水号；仅在业务前缀、唯一粒度、软删和并发语义齐全后实施内部自动编号。当前 S0、S4 已完成，因 22 项内部候选均缺少完整业务规则，S1—S3 不进入代码。

**Architecture:** 复用现有服务层事务、数据库唯一约束和写后回读；`CodeGenerationService` 仅适用于“租户 + 当日日期前缀”编号，冲突重试由业务服务负责，`includeDeleted=true` 也仅对实现 `DeletedCodeSource` 的 Mapper 生效。禁止把它扩展为万能编号平台、猜测项目/合同粒度、用前端生成序号或改写历史编号。

稳定键：`BUSINESS-CODE-AUTOMATION-GOVERNANCE`

## 1. S0 事实冻结

当前 30 项均未由服务端自动生成，原“27 个内部候选 + 3 个版本字段”前提不成立：

| 分类 | 数量 | 字段 | 裁决 |
| --- | ---: | --- | --- |
| 内部自动候选 | 22 | 仓库、招采、退货；计划、计划期间、进度纠偏；质量计划、检查、后果；技术方案、会审、RFI、交底、归档；收尾、分项验收、竣工验收、质保、缺陷、移交；完工预测、成本纠偏 | `NEEDS_CONFIRMATION`；逐项补齐规则前保持人工输入 |
| 外部/契约人工 | 3 | 供应商报价、图纸编码、合同清单编号 | 保持人工；不得由系统伪造外部事实 |
| 版本语义 | 3 | 预算版本号、目标成本版本号、图纸版本号 | 保持既有版本链；不得改为日流水 |
| 关系/期间语义 | 2 | WBS任务编码、计量期间编码 | 保持人工；前者被父/前置任务引用，后者按合同唯一 |

证据边界：

- 典型 DTO 使用 `@NotBlank`，V2 表单使用 `required`，服务层直接保存输入值。
- 现有自动计量单 `measureCode` 不等于计划内的计量期间 `periodCode`。
- 多数目标域为 JDBC 直写，不能假定已有实体 Mapper、唯一约束或软删查询。
- 仓库编码只确认 `NOT NULL`，未确认对应业务唯一约束。

## 2. 范围与非目标

范围：

1. 维护上述 30 项唯一分类。
2. 为 22 项内部候选补齐前缀、租户/项目/合同粒度、软删复用、冲突重试和历史兼容规则。
3. 规则获批后，服务端忽略客户端内部编号并返回实际值，V2 只展示写后回读结果。
4. 每个实施域覆盖生成格式、跨租户、唯一冲突、软删和回读。

非目标：

- 不修改主数据、系统管理、外部/契约编号或版本链。
- 不新增通用编号后台、DSL、前端算法或依赖。
- 不改历史数据，不放宽唯一约束。
- 本轮不实施 22 项规则未冻结的代码。

S1 规则缺失属于业务真实性门，不以猜测解决；按用户“无法判断可暂时跳过”授权，本轮跳过 S1—S3，继续其余主线任务。

失败分类：`quality_or_security`（业务规则与唯一约束证据不足）；非代码、环境或部署失败。

## 4. 实施不变量

1. 内部编号仅由服务端生成；前端不计算、不预占。
2. 唯一粒度必须与数据库约束一致，不能用租户级流水替代项目/合同级规则。
3. 当前生成器不提供通用冲突重试；每个业务服务须捕获唯一冲突并有限重试。
4. 软删复用必须有明确含删查询；未实现 `DeletedCodeSource` 时不得假定 `includeDeleted=true` 有效。
5. 外部/契约编号、版本号、WBS关系键和计量期间保持原语义。
6. 创建成功后写后回读，页面只展示服务端返回值。

## 5. 后续验收

- 22 项内部候选逐项取得业务规则，不允许批量套用同一前缀或唯一粒度。
- 每个实施域的新建接口不依赖客户端内部编号。
- 生成、重复重试、跨租户、软删和写后回读通过。
- 目标后端测试、V2 unit/type-check/build、相关真实页面创建复读通过。
- 30 项始终归入“已自动化、保留人工、版本/关系语义、等待规则”之一。

## 6. 风险与回滚

| 风险 | 控制与回滚 |
| --- | --- |
| 外部编号或版本号被误自动化 | 分类门禁止进入实现；回退目标域改动，不改历史值 |
| 唯一粒度错误 | 先以业务约束和数据库索引双证据冻结规则 |
| 并发重复 | 业务事务内有限重试，数据库唯一约束最终裁决 |
| 软删冲突 | 显式含删查询或保持不复用 |
| 范围膨胀 | 不建编号平台；一次只实施一个规则完整的业务域 |
