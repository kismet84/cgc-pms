# 第61条主线：前端共享组件与推送前质量门禁整改

**Goal:** 修复 `V2Select` 原生控件迁移引起的 E2E 交互契约、响应式无障碍和测试 mock 漂移，并建立共享组件/API 变更在推送前可执行的最小质量门禁，避免完整浏览器问题首次在远端 CI 暴露。 **Architecture:** 复用现有原生 `<select>`、Playwright migration gate、Axe、Vitest、类型检查、构建和 CI 汇总；以共享组件稳定 DOM/ARIA 契约、以确定性请求 mock 作为 E2E 边界、以版本化脚本承载本地门禁。不引入新的 UI 组件库、E2E 框架、业务 API、平行 mock 服务或生产环境流程。

> 日期：2026-08-01
> 分支：`master`
> 状态：`IMPLEMENTED_LOCALLY / SAME_SHA_CI_PENDING`
> 依据：`32872e6a1 refactor(frontend): simplify v2 workspaces and navigation` 及其后续 E2E/mock 修复差异
> 授权：主线授权后本地前端、测试、门禁脚本、CI 契约与文档实施
> 未授权：commit、push、PR、合并、发布、生产或生产数据库操作

## 问题定性

- 共享组件由自定义 `button/listbox/role=option` 改为原生 `<select>`，业务 `v-model` 和类型仍兼容，导致类型检查无法发现旧 E2E 选择器已经失效。
- 响应式布局隐藏 `.v2-field__label`；原生控件在部分断点失去可访问名称，属于真实无障碍缺陷，不是测试误报。
- 页面新增字典、工作区汇总和认证导航请求，部分 E2E route mock 未同步，未拦截请求进入真实后端或认证流程，产生 500、登录页和空白状态。
- `git` 没有生效的 `pre-push` 钩子；常规本地 type-check、lint、unit、build 不覆盖 DOM 交互、断点 CSS、Axe 和网络 mock，因此远端 E2E 成为第一道完整门禁。
- 失败分类：`quality_or_security / DELIVERY_GATE_OMISSION`；不得归类为随机 CI、网络或运行器故障。

## 范围与非目标

- 范围：`V2Select` DOM/ARIA/键盘/禁用/必填契约；所有 V2Select 消费者 E2E 交互；响应式 Axe 断点；确定性 API mock 与未处理请求检测；本地推送前门禁入口；CI 契约和文档。
- 范围：保留原生 `<select>` 方案，禁止恢复第二套自定义下拉实现。
- 非目标：业务页面重做、业务 API/数据库字段变化、认证模型重构、生产部署、Git 交付、浏览器运行态刷新。

## 实施约束

- 共享组件变更必须先检索全部调用方和 E2E 选择器，再改实现；禁止只修首个失败 spec。
- 确定性 E2E 禁止静默访问真实后端；未声明请求必须记录 URL 并失败，认证失败只能在专门的负向用例中出现。
- 不通过隐藏前端按钮代替无障碍或权限校验；`hideLabel` 不能破坏可访问名称。
- 不把本地门禁通过等同于同 SHA CI 通过；首次非 Draft PR 仍须满足 CI 门禁规则。
- 主线实施保留工作区既有脏改动；本计划本身只登记范围，不覆盖他人代码。

## 验收标准

- `V2Select` 在桌面、中等断点和移动断点都具备稳定可访问名称；键盘、禁用、必填、错误提示和空选项行为有单元证据。
- 所有迁移门 E2E 使用原生 select 交互，不再查找已删除的自定义 `button/listbox` 结构。
- 确定性 E2E 无意外 500、认证跳转、未处理 API 请求；新增 API mock 覆盖最小字段，不复制生产数据。
- 本地门禁失败可阻止推送；CI `e2e` job 仍运行完整 migration specs，且 build-summary 反映失败状态。
- 通过 `pnpm type-check`、`pnpm lint:check`、`pnpm test:unit`、`pnpm build`、受影响 E2E/Axe、`pnpm test:e2e:migration-gate` 与 `git diff --check`。
- 同一 SHA 的本地证据和 CI 证据可追溯；不执行生产、数据库、commit、push 或 PR。

## 风险、恢复与回滚

| 风险 | 控制 | 回滚 |
| --- | --- | --- |
| 原生控件行为与业务页面假设不一致 | 共享契约测试 + 全调用方 E2E 检索 | 仅回退组件契约变更，保留已迁移测试证据 |
| 隐藏标签造成无障碍回归 | `aria`/label 断言 + 三断点 Axe | 恢复可视或视觉隐藏但语义保留的标签实现 |
| mock 漏口掩盖真实接口问题 | 未处理请求失败、最小响应 schema 断言 | 回退新增 mock，保留失败请求清单，禁止放宽为 catch-all |
| 推送前门禁过慢影响开发 | 受影响 spec 本地、全量 spec CI；超时记录分类 | 关闭本地自动入口但保留显式命令和 CI 强制门禁，回主线裁决 |
| CI 与本地环境差异 | 固定 Playwright/浏览器/Node 入口，绑定 SHA | 以 CI 失败为准，按失败分类修复环境或代码，不跳过门禁 |
