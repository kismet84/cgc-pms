# 第74条主线：业务单据模板三栏布局调整

**Goal:** 将 V2“业务单据模板”页面调整为“业务类型 / 模板 / 详情”三栏主从布局，使用户可依次选择业务类型、模板和版本，并在同一工作区查看版本详情。 **Architecture:** 复用现有 Vue 页面、`V2Card`、CSS Grid、`businessOptions`、`selectedVersionId` 及模板服务；不新增组件、依赖、接口或后端逻辑。版本表保留在详情栏，增加可访问版本选择；窄屏退为单栏。此项属于现有设计系统内的小型布局调整，不生成视觉资产，不扩展模板治理能力。

## 1. 范围与非目标

### 1.1 范围

- 顶部保留页面标题、刷新和新增模板操作。
- 左栏展示业务类型列表，替代顶部业务类型下拉框。
- 中栏保留模板列表、状态、选择和分页。
- 右栏保留版本表、新建版本、版本操作及所选版本详情。
- 支持鼠标或键盘选择版本；选中状态与右栏详情联动。
- 完成桌面、平板和手机响应式及页面无水平溢出验收。

### 1.2 非目标

- 不修改模板、版本、默认绑定或发布状态机。
- 不修改后端、数据库、权限、路由、服务接口和公开类型。
- 不增加 HTML 在线预览、模板设计器或新版本字段。
- 不重构公共组件，不新增依赖，不顺带处理其他页面。
- 不修改当前已有 Backlog、计划索引、项目地图及非任务脏改动。

## 2. 页面与交互契约

### 2.1 业务类型栏

- 使用现有五个业务类型及中文名称。
- 当前类型显示明确选中态和 `aria-pressed="true"`。
- 选择新类型后复用现有刷新流程，重置分页并选中首个模板及首个版本。
- 重复选择当前类型不重复请求。

### 2.2 模板栏

- 保留模板名称、编码、启停状态和每页十条分页。
- 选择模板后读取服务端详情并默认选择首个版本。
- 当前业务类型无模板时显示既有空状态，并清除上一类型的模板及版本详情。

### 2.3 详情栏

- 上部保留版本、状态、契约、默认标记、发布时间和操作菜单。
- 版本号使用真实按钮选择，提供选中态和 `aria-pressed`。
- 选择版本只更新本地 `selectedVersionId`，不得产生额外 API 请求。
- 下部展示所选版本已有内容哈希和字段清单。
- 新建版本、编辑、发布、设为默认、停用及权限控制保持原行为。

### 2.4 响应式

- 宽度大于 `1180px` 时显示三栏，详情栏占最大宽度。
- 宽度不大于 `1180px` 时按业务类型、模板、详情顺序折叠为单栏。
- 版本表宽度不足时只允许表格容器横向滚动；页面本身不得横向溢出。
- 编辑弹窗继续沿用现有 `680px` 表单断点。
