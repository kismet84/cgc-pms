### 2.1 VCG-B01：弹窗样式

参考包 SHA-256：`9625A3461572A67DAE9C132ACBF512B0CD2D9165B06EDDD7AB9346B397A4029B`。参考包只作为视觉输入；验收以本节可复验合同为准，避免依赖仓库外文件长期存在。

视觉合同：

1. 采用冷色浅底的半透明液态玻璃面板：柔和背景模糊/饱和、细亮边框、多层轻阴影和克制高光；所有值进入各端既有 token，不复制参考包中的裸色、裸圆角和裸阴影。
2. 遮罩保留页面上下文但必须降低干扰；正文、标签、金额、状态和危险提示的对比度优先于玻璃效果。
3. 保留清晰的标题区、可滚动正文区和操作区。长内容的操作区可固定；内容不得被页脚遮挡。
4. 按业务内容使用小型确认、中型表单、大型详情三档尺寸；参考包的 `1040px` 只适用于详情型弹窗，不得成为所有弹窗默认宽度。
5. 移动端使用近全宽、底部对齐的弹层形态，最大高度不超过可视区；主操作突出，次操作可换行但不得改变业务语义。
6. 不支持 `backdrop-filter`、启用高对比度或 reduced-motion 时提供不透明表面、可见边框和无位移动画的可用降级。
7. V3唯一结构与视觉基线为 `http://localhost:4173/v2/src/components/preview/index.html` 的“审批详情”：标题与状态、说明、信息卡、表格卡、页脚和按钮必须复用共享类；详情面板自然高度，只有内容超过视口上限时正文独立滚动。

实现边界：

- V2只调整 `V2Dialog` / `V2ConfirmDialog` 的既有 token 和共享样式；保留当前焦点陷阱、Escape、顶层弹窗判定、焦点恢复、ARIA和 Teleport 行为。现有 V2 已具备玻璃基线，只做对标收敛，不重建组件。
- Legacy只通过 Ant Design Vue token、`global-app-redesign.css` 和既有 `lg-modal-form` 共享层收敛；不逐页复制 `.ant-modal-*` 覆盖，不替换 Ant Design Vue 弹窗行为。
- 参考包脚本仅恢复焦点，没有 Tab 焦点陷阱；不得复制其交互实现。业务关闭门、加载锁、危险确认和权限行为保持现状。
- 弹窗内卡片、表格和按钮继续复用各端现有组件/样式，不从参考包引入第三套结构。

专项验收：

1. 选取两端的确认、表单、详情三类代表弹窗；在 `1440 / 1024 / 390` 视口核对尺寸、滚动、操作区、长中文、金额和状态可读性。
2. 键盘焦点不能逃出弹窗；Escape、遮罩关闭策略、关闭后焦点恢复、加载中禁止关闭、嵌套/连续弹窗行为无回退。
3. axe、文本/焦点对比度、200%缩放、reduced-motion及无 `backdrop-filter` 降级通过。
4. 共享入口之外不新增弹窗材质；触及文件不新增裸视觉值或跨端依赖。

## 7. 风险与回滚

| 风险 | 控制与恢复 |
| --- | --- |
| 跨端合并破坏 Clean-room | 两端独立清单与门禁；出现跨端依赖立即回退相关变更 |
| 大爆炸清理造成样式回归 | 渐进门禁，只治理触及范围；按试点文件回退 |
| 抽象抹平业务语义 | 只有语义、交互和无障碍合同一致才复用，否则保留页面私有 |
| 删除低使用组件影响隐藏调用方 | 删除前要求静态调用归零、动态冒烟和可恢复提交 |
| 既存债务使门禁不可用 | 基线存量与新增违规分开计数；先阻止净新增，再逐批清理 |
| 玻璃效果降低可读性或性能 | 对比度和交互优先；弱化模糊/高光，低能力环境回退为不透明 token 表面 |

本轮已实施 Legacy 与 V2 共享弹窗入口整改，并完成 V2 V3共享结构推广。恢复方式为回退两端本轮弹窗 token、共享 CSS、V2 标题后缀 slot、预览实例、四类共享面板类迁移和对应契约测试；无需恢复页面私有视觉，不影响数据库、运行数据、路由、权限或正式业务入口。
