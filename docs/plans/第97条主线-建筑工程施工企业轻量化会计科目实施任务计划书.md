# 第97条主线：建筑工程施工企业轻量化会计科目实施

**Goal:** 在不改写既有成本事实和已过账凭证的前提下，落地固定会计科目树、五类辅助核算要求、八类合同履约成本与主营业务成本映射，并把采购付款、工程结算、回款及成本结转接入同一可审计会计凭证链。 **Architecture:** `cost_item` 继续作为项目成本事实账本；`cost_subject` 增加总账目录标识并承载固定会计科目，历史项目成本科目继续只服务成本归集。会计凭证明细显式保存总账科目外键，凭证头保存项目、合同、往来单位、部门和员工辅助维度；新生成凭证按固定科目政策失败关闭，历史凭证只读保留。

## 1. 事实边界

1. 当前 `cost_subject` 同时保存项目成本分类和少量总账科目；本轮增加显式总账标识，避免 `1122` 等总账科目进入成本规则、项目范围或 `cost_item` 新选择。
2. 现有 `5401.*` 项目成本分类及其历史引用不删除、不改写；新会计凭证通过八类映射进入 `1451.01～1451.08`，成本结转进入 `6401.01～6401.08`。
3. 现有 `1002-BANK`、`1122-AR`、`1123-PREPAY`、`2202-AP`、`2203-ADVANCE` 仅保留历史读取；新凭证使用正式科目，预付款以应付账款借方余额表达，预收工程款使用合同负债。
4. 项目、合同、往来单位、部门、员工是辅助维度，不创建为会计科目；必填、合同类型、往来单位类型和关闭项目校验由服务端执行。
5. 既有项目成本、收入、回款、应收账龄、资金和合同分析页面作为报表权威入口；不复制第二套报表和账本。

## 3. 非目标

- 不引入完整 ERP 总账、现金流量表、合并报表、外币、数量核算或多账簿。
- 不重做第96条成本规则、项目成本配置和历史重算，不从会计凭证反向重复生成 `cost_item`。
- 不自动改写历史凭证的科目编码、金额、日期或辅助维度；无法识别历史值只进入待复核清单。
- 不扩大非财务写权限，不允许前端绕过服务端辅助核算、期间和项目状态门禁。

## 4. 回滚

1. 代码回滚不删除迁移；新表和新增列保留兼容读取。
2. 新策略异常时停止生成新凭证，历史 DRAFT/POSTED 凭证和 `cost_item` 不受影响。
3. 尚未过账的成本结转凭证可按现有凭证复核/冲销规则处置；已过账事实仅追加冲销，不 UPDATE/DELETE 原行。
