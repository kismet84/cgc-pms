# 第65条主线：材料字典资料导入与双价展示

**Goal:** 在材料字典增加空白系统模板导出、标准模板批量导入、当前含税信息价和采购价展示；允许将整理后的材料资料逐行补充或更新到当前租户材料库，并保证价格来源可追溯。 **Architecture:** 复用现有 `md_material`、两级材料分类、材料验收明细、V2 请求层、权限与 CSRF 契约；当前含税信息价作为材料主数据的单一当前值，采购价由服务端按最近已审批验收事实批量派生。不建立信息价历史表、平行采购价格账、模糊 OCR 匹配平台或第二套导入框架；原始武汉多工作表资料先整理为系统模板后导入。

## 1. 已确认需求

### 1.1 材料字典列表

列表按以下顺序展示：

1. 材料编码
2. 材料名称
3. 材料分类
4. 规格型号
5. 计量单位
6. 含税信息价
7. 采购价
8. 默认税率
9. 状态
10. 操作

含税信息价来自标准模板导入；采购价来自服务端最近已审批材料验收明细。价格为空时显示 `—`，金额始终使用服务端十进制字符串，不在前端转为浮点权威值。

### 1.2 用户已选定规则

- 导入全部材料及含税信息价；除税价不导入。
- 只保留当前含税信息价，不保留月度历史。
- 导入只接受系统标准模板，不直接解析原始武汉多工作表文件。
- 导出空白模板，不预填当前材料。
- 未匹配材料由系统自动生成唯一材料编码。
- 模板一级、二级分类自动创建或复用两级材料分类。
- OCR 校核状态不自动停用材料；新材料默认启用。
- 行级错误不阻断其他合法行，返回部分成功结果。
- 匹配到现有材料时只更新含税信息价及其来源元数据，不覆盖名称、分类、规格、单位、品牌等主数据。
- 同一分类、名称、规格、单位相同但含税价不同的记录独立建档，并标记待校核，不静默取首条或末条。
- 采购价取当前租户内最近已审批验收明细单价，包含直耗验收；不使用库存移动加权成本。

## 2. 输入资料基线

用户提供的 `2026年7月武汉市建设工程综合价格信息.xlsx` 已只读检查：

- 12 个工作表，其中 1 个说明表、11 个价格数据表，共 2115 条材料记录。
- 主要字段为分类、名称、规格型号、单位、含税价、除税价、推定税率、备注、来源页码和校核状态。
- 126 条“已人工校正”、512 条“自动识别（规则校正）”、1477 条“自动识别，建议抽检”。
- 54 条缺规格、1 条缺单位；现有材料模型允许规格和单位为空，导入不得因这两项为空直接丢弃记录。
- 仅按名称、规格、单位归一化后有 5 组重复键、14 条记录；加入分类路径后仍有 1 组 2 条同键不同价记录，含税价分别为 43 和 45。

该文件不是受支持的直接导入格式。实施后先下载空白系统模板，将 11 个价格表整理到模板，再上传；不得在导入服务内加入武汉版式专用解析分支。

## 3. 范围与非目标

### 范围

- 材料字典空白 `.xlsx` 模板生成与下载。
- 标准模板 `.xlsx` 解析、行级校验、自动分类、自动编码、补充/更新、结果汇总。
- `md_material` 当前含税信息价及其来源、月份、校核与冲突标记。
- 材料列表/详情服务端 VO 和 V2 页面双价展示。
- 最近已审批验收单价的当前页批量查询、租户隔离与来源追溯。
- MySQL/H2 等义 migration、后端/前端测试和真实浏览器验收。

### 非目标

- 直接导入当前武汉多工作表版式或建立通用 OCR/字段映射平台。
- 保存除税价、历史信息价、价格趋势、供应商分价、项目/仓库分价或价格预测。
- 将采购价写入 `md_material`、前端计算采购价或改写库存平均成本。
- 自动修正文档中的 OCR 名称、规格、单位或备注。
- 新增独立导入权限、审批流、后台任务队列或通用 Excel 框架。
- 修改、提交或发布当前工作区其他主线的脏改动；生产、部署和发布全部排除。

## 4. 核心不变量

- 所有读取、匹配、分类创建、材料写入和价格查询均限定当前租户；跨租户统一按不存在处理。
- 信息价只有一个当前值；每次成功导入覆盖当前值及对应来源元数据，不产生历史记录。
- 采购价只读派生：`mat_receipt.approval_status='APPROVED'`，验收明细合格数量和单价均大于零，按验收日期降序、明细 ID 降序取第一条；不按供应商、项目、仓库过滤，包含直耗。
- 后端批量查询当前页采购价，禁止逐材料 N+1 查询；前端只展示返回字符串。
- 已有材料主数据不被批量导入改名、改分类、改规格、改单位、改品牌、改税率或改状态。
- 自动匹配只做确定性归一化，不做相似度、拼音、编辑距离或 OCR 猜测。
- 结构级错误整份拒绝；行级错误只回滚当前行。任何失败行必须包含行号、稳定错误码和可操作说明。
- 同键不同价必须保留两条来源事实并显式标记冲突；禁止任取一条覆盖。
- 文件结构、MIME、扩展名、CSRF、权限和租户边界均 fail-closed。

## 6. 数据模型与公共契约

### 6.1 最小数据变化

在下一可用 MySQL migration 与 H2 等义 migration 中为 `md_material` 增加：

| 字段 | 建议类型 | 用途 |
| --- | --- | --- |
| `tax_inclusive_info_price` | `DECIMAL(19,6) NULL` | 当前含税信息价 |
| `info_price_period` | `CHAR(7) NULL` | 当前价格月份，格式 `YYYY-MM` |
| `info_price_source` | `VARCHAR(255) NULL` | 来源文件、发布文号或资料名称 |
| `info_price_verification_status` | `VARCHAR(32) NULL` | 原始校核状态 |
| `info_price_external_row_key` | `VARCHAR(128) NULL` | 外部行稳定标识，用于冲突消歧与重导 |
| `info_price_review_required` | `TINYINT NOT NULL DEFAULT 0` | 同键冲突或需人工复核标记 |

不增加信息价历史表，不增加 `purchase_price` 字段。金额字段使用 `BigDecimal`，API 使用普通十进制字符串。

### 6.2 模板

`GET /materials/import-template` 返回附件 `材料字典导入模板.xlsx`，包含：

- `材料导入`：仅表头，无现有材料数据。
- `填写说明`：必填、默认值、格式、匹配、冲突和部分成功规则。

`材料导入` 固定列顺序：

1. 材料编码（选填）
2. 材料名称（必填）
3. 一级分类
4. 二级分类
5. 规格型号
6. 计量单位
7. 品牌
8. 含税信息价（必填、正数、最多 6 位小数）
9. 信息价月份（`YYYY-MM`）
10. 信息价来源
11. 校核状态
12. 默认税率
13. 状态（空值默认 `ENABLE`）
14. 外部行标识
15. 备注

模板下载权限复用 `material:dict:list`。模板 MIME 与 `Content-Disposition` 必须正确，文件能被 Excel/LibreOffice 正常打开。

### 6.3 导入接口

`POST /materials/import` 接收 `multipart/form-data` 字段 `file`，只允许 `.xlsx`：

- 管理员直接允许；普通用户必须同时具备 `material:dict:add` 和 `material:dict:edit`。
- 复用现有 `FileTypeValidator` 的扩展名、MIME、魔术字节和 20MB 上限，不新增文件安全路径。
- 使用 Apache POI 生成和解析 `.xlsx`；项目没有现成 Excel 依赖，禁止自行实现 OOXML ZIP/XML 解析器。
- 工作簿损坏、缺少 `材料导入`、表头缺失/重复或版本不支持属于结构级错误，整份不写入。
- 数据行顺序处理，每行独立事务；分类、材料及当前价在同一行事务内写入并回读。

响应：

```text
total
created
priceUpdated
conflictsCreated
skipped
failed
errors[{row, code, message}]
```

错误列表必须覆盖全部失败行，不只返回首个错误；前端展示汇总和错误表，不把部分成功表述为整批成功。

## 7. 匹配、分类与编码规则

### 7.1 归一化

对分类名称、材料名称、规格和单位仅执行：Unicode NFKC、首尾空白删除、连续空白折叠、拉丁字母统一大小写。不得替换疑似 OCR 字符或合并近似单位。

### 7.2 匹配顺序

1. 材料编码非空：按当前租户精确匹配；存在则只更新当前信息价，编码不存在则使用该编码创建。
2. 编码为空：按规范化后的材料名称、规格、单位查找。
3. 唯一匹配：只更新当前信息价及来源元数据。
4. 多个匹配：再按一级/二级分类路径与外部行标识消歧。
5. 无匹配：创建材料并生成编码。
6. 仍有同键不同价：每条独立创建，`info_price_review_required=1`，不得覆盖。

同键同价且来源行相同的重导视为幂等更新或跳过；不得重复新增。

### 7.3 自动分类

- 一级分类按当前租户、根节点和规范化名称复用；不存在则创建。
- 二级分类按当前租户、父分类和规范化名称复用；不存在则创建。
- 分类编码使用 `IMP-CAT-` 加分类完整路径 SHA-256 摘要前缀，数据库唯一约束为最终裁决。
- 两级分类均为空时使用当前租户启用的 `UNCATEGORIZED`；只有二级分类时视为行级错误。
- 自动创建分类默认 `ENABLE`，不修改同名既有分类的名称、顺序或状态。

### 7.4 自动材料编码

- 基础编码使用 `MAT-IMP-` 加“分类路径、名称、规格、单位”规范化结果的 SHA-256 摘要前缀。
- 冲突记录再加入外部行标识；外部行标识为空时使用模板行号，并设置待校核标记。
- 生成前按当前租户检查唯一性；摘要碰撞时增加确定性后缀，不使用随机数或扫描最大编号。
- 编码生成后保持不可修改；后续模板可显式填写该编码更新当前价格。

## 8. 分阶段实施

### 8.1 G0/G1：基线与契约冻结

1. 重新核对当前 HEAD、工作区、最高 migration 版本和第63/64条文件归属；实现文件不得混入其他主线 diff。
2. 固定上述模板列、API、错误码、匹配、分类、编码、冲突和采购价规则。
3. 建立字段映射表，证明原始武汉资料可人工整理到模板；不为其添加专用解析代码。

### 8.2 G2：迁移

1. 新增下一可用 MySQL 与 H2 等义 migration；不得修改已应用 migration，也不得复用当前其他主线占用的版本号。
2. 新字段全部允许历史空值；现有材料无需回填虚构信息价。
3. 验证空库、现有历史库升级、字段精度、默认值、租户查询和回滚兼容。

### 8.3 G3：服务端

1. 在材料域增加一个薄导入服务，集中模板、解析、匹配、分类、编码和逐行结果；Controller 只做 HTTP/权限映射。
2. 结构校验完成后逐行开启独立事务；失败捕获为行错误，成功后回读材料、分类和当前价。
3. 材料当前页查询后，用一次批量 SQL 返回每个材料最近已审批验收价及来源；详情复用同一查询规则。
4. 扩展请求响应对 Excel Blob 的支持，不改变 JSON/PDF 既有行为。

### 8.4 G4：V2 页面与浏览器

1. 材料字典工具栏新增“导出模板”“导入资料”；导入按钮仅管理员或同时具备新增/编辑权限时可见。
2. 导入弹窗限制 `.xlsx`，展示填写规则、上传状态、部分成功汇总和全部失败行。
3. 成功或部分成功后重新请求材料页；不得在前端累计总数、合并价格或猜测材料状态。
4. 表格增加含税信息价、采购价；详情展示月份、来源、校核、待复核及采购价来源。
5. 浏览器验证下载、上传、部分成功、冲突、权限、分页、桌面/窄视口和控制台。

### 8.5 G5：收口

1. 输出正式质量报告到 `docs/quality/`，绑定实际分支、HEAD、diff、migration、自动化、API、数据库和浏览器证据。
2. 回写本计划与计划索引；只有实施获正式承接时再创建/更新 Backlog 和当前焦点。
3. 统计新增后续项、关闭后续项和净变化；无唯一载体的遗留项使结论为“不通过”。
