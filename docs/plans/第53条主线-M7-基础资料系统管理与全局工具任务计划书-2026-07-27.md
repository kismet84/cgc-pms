# 第53条主线 M7 基础资料、系统管理与全局工具任务计划书

**Goal:** 将剩余 24 条 `LEGACY_ONLY` 路由迁移为可验收的 Clean-room V2 页面或受控确定性重定向，保持基础资料、成本科目、流程配置、系统管理、个人设置和错误页的 URL、权限、角色、租户、状态与后端事实不变。 **Architecture:** 复用现有 V2 应用壳、会话、权限守卫、请求层和后端接口；按“登录与错误深链 → 个人与帮助 → 基础资料 → 成本科目 → adminOnly 与流程配置 → 系统管理 → 全量收口”串行推进。禁止复制 Legacy UI、建立第二套主数据、放宽 ADMIN/SUPER_ADMIN 边界、让前端裁决引用保护，或把数据库清理当普通页面操作。

## 3. 权威事实与禁止项

| 事实 | 权威来源 | V2 职责 | 禁止 |
| --- | --- | --- | --- |
| 登录与当前用户 | 同源 HttpOnly Cookie、`/auth/user-info` | 提交凭据、恢复会话、展示当前用户 | token 入存储、URL 或日志 |
| 当前用户资料与偏好 | `/profile`、`/profile/preferences` | 白名单编辑、写后回读 | 修改角色、租户、组织或他人资料 |
| 合作方、组织、材料 | 既有 Controller/Service | 查询、受权维护、写后回读 | 前端平行主数据或状态推进 |
| 成本科目 | 版本、规则、范围、引用与影响服务 | 展示服务端事实、提交受权命令 | 前端判断可删、引用保护或规则命中 |
| 流程配置 | 工作流模板与节点服务 | 维护配置、排序并回读 | 第二套工作流或本地审批裁决 |
| 用户、角色、权限、字典、模板 | 系统管理与文档服务 | 按独立权限读写 | ADMIN 兜底替代权限、合并权限边界 |
| 审计 | 审计日志服务 | 只读查询 | 修改、删除或伪造历史 |
| 数据维护 | 环境守卫和后端受控端点 | 最后接入、双确认、失败关闭 | 生产可达、自动清库、浏览器真实执行 |

ID、金额和稳定数值继续使用服务端返回字符串；空值与 `0` 区分。所有写侧成功后重新读取服务端事实。

后续切片启动前必须在对应 Issue 内关闭以下已确认缺口，不另建悬空项：

- `/org` 的 `org:query` 与 API `org:list`、材料的 `material:query` 与 `material:dict:list`、字典的 `system:dict:query` 与 `system:dict:list`、权限页的 `system:permission:query` 与菜单 API `system:menu:query` 必须先冻结一致矩阵。
- `/system/data` 仅允许非生产 `SUPER_ADMIN`，ADMIN 不可见且不可执行；确认码继续由后端校验。
- 用户管理接入前必须拒绝非法状态、当前管理员自停用、最后管理员停用和受保护字段越权修改。
- 合作方电话、银行账号不得进入前端缓存或日志；审计页缺少 `audit:query` 时不得发请求。
- `BIZ-001/M7` 退出门必须裁决改密后的 access/refresh token 撤销与多会话策略；验收为改密后受撤销令牌不可继续访问或刷新，不得用本切片页面通过替代生产安全闭环。

## 5. Gate

### Gate A：启动门

- 分支、状态、基线 SHA、24 条路由、非目标和回滚已冻结。
- 用户已授权启动第55条 M3；`ISSUE-053-036～040` 已通过，`ISSUE-053-041` 是唯一 Ready。

### Gate B：切片门

- 当前 Issue 的契约、unit、type、lint、clean-room boundary、route ledger、build 和目标 E2E 通过。
- 普通角色、缺权限、匿名深链、query/hash、刷新和错误边界按切片验证。
- 当前 Issue 通过并完成报告与治理回写后，才启动下一 Issue。

### Gate C：adminOnly 门

- router 与 navigation 同时要求既有 ADMIN/SUPER_ADMIN 角色和精确 permission。
- 普通角色即使误配系统权限也失败关闭；审计页继续按 `audit:query` 独立只读。
- 该门通过前，系统管理业务页面不得标记 `V2_ACCEPTED`。

### Gate D：退出门

- 台账为 `0/87/0`，无占位页或 Legacy Vue/CSS import。
- 多角色、三视口、键盘、focus、axe、深链、写后回读和失败注入通过。
- 后端/V2 全量、demo 验证和内置浏览器 QA 通过；悬空项为 0。
