## 6. 风险与回滚

| 风险 | 控制与回滚 |
| --- | --- |
| 本地根路径演练误改正式配置 | 使用独立演练文件和临时容器/端口；停止演练服务即可恢复 |
| V2 base、Router base、Nginx fallback 不一致 | 同一制品验证 `/assets`、深链刷新和 API；失败立即回到 Legacy |
| 测试数据污染 | 只用既有本地 dev + demo 载入与清理流程；写后回读并校验清理 |
| 工作区既有改动被覆盖 | 每批修改前复读 Git 状态与目标 diff；只追加或精确修改任务文件 |
| 本地证据被误作生产证据 | 报告固定标注 local dev + demo；生产继续受第55条发布门阻塞 |

## 7. 停止条件

- 任一权限、租户/项目范围、金额、库存、审批或会计守恒失败。
- V2 需要导入 Legacy Vue/CSS/store/layout 才能通过。
- 根路径切换或回滚不能恢复健康、登录、API、静态资源或深链。
- 验收需要生产连接、生产数据、生产 Secret、正式入口或 Legacy 删除。
- 出现无法安全保留的重叠未知修改。
