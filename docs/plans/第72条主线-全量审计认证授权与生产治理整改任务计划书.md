## 3. 不变量

- 登录前必须显式确定租户；未知租户、用户或密码统一返回 `AUTH_FAILED`，不得泄露账号存在性。
- Refresh 只信任已验签 token 内的 `tenantId + userId`，不得使用请求方补交的租户值。
- 所有用户、角色、权限和凭据查询同时绑定租户与对象 ID；禁止全表绕过租户线后仅按用户名或用户 ID 查询。
- 投标未绑定项目时沿用既有租户级可见规则；绑定项目后必须满足 `tenant access AND project access`。
- 项目过滤进入 SQL 或共享对象门禁；禁止分页后过滤、Controller 补丁或仅隐藏前端选项。
- prod 缺值、空值、localhost、示例域名或不安全 JDBC 参数必须在应用对外提供服务前失败退出。
- 第三方 Action 固定完整 commit SHA，容器固定 OCI digest；本地 Action 路径不改写。
- PR 功能分支等价 CI、PR CI、post-merge 轻量核验和目标环境发布证据互不替代。
