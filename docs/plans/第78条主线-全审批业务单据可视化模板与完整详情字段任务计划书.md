# 第78条主线：全审批业务单据可视化模板与完整详情字段

**Goal:** 建立覆盖全部审批业务类型的可视化单据模板能力，使模板字段来自对应业务对象的完整详情契约，支持 A4 纵横向画布、实时 HTML 预览、版本治理和 PDF 生成；以分包计量为首个完整参考实现，最终达到全部启用审批类型 100% 覆盖。 **Architecture:** 复用现有模板版本、Provider、受限 HTML 渲染、PDF 生成、业务详情 Service 和权限体系；将字段目录归入各业务 Provider，禁止扫描数据库、反射实体或使用审批流程字段兜底。新增可持久化画布模型，由服务端生成 HTML 和字段清单。旧源码模板保持兼容，不引入第三方设计器、脚本表达式、外部资源或新渲染引擎。

## 1. 编制依据与当前结论

### 1.1 编制依据

1. 根规则要求正式计划书明确目标、架构、范围、非目标、验收、风险、回滚和 G0～G5 门禁。
2. 现有模板治理已具备受限源码、稳定字段目录、单层循环、模板版本生命周期、默认绑定、预览和 PDF 生成基础。
3. 当前 `DocumentTemplateFieldCatalog` 只覆盖付款、结算、采购申请、采购订单、材料验收五类业务。
4. 当前 V2 模板页面没有加载服务端字段目录，仍展示并编辑字段清单 JSON。
5. 当前模板版本只保存 HTML 与字段清单，不能可靠恢复拖拽位置、尺寸、表格列和 A4 页面配置。
6. 分包计量详情的权威读取入口是 `SubMeasureService.getById`，返回主详情、项目/合同/分包商/任务显示信息及计量清单。

### 1.2 立项结论

- 字段覆盖单位是审批业务类型 `businessType`，不是审批节点。
- 字段来源是业务对象完整详情契约，审批记录、审批意见和流程节点不是业务详情字段。
- 每种启用审批类型必须提供独立 Provider；未配置时必须明确阻断，不允许通用假字段回退。
- 分包计量作为首个完整参考实现，但主线完成条件是全部启用审批类型 Provider 覆盖率达到 100%。

## 2. 范围与非目标

### 2.1 本计划范围

1. 服务端动态审批业务类型目录。
2. 每种审批类型独立完整详情 Provider。
3. 主详情、关联显示字段和嵌套业务明细集合。
4. A4 纵横向画布、拖拽、缩放、属性编辑和实时预览。
5. 画布模型持久化、受限 HTML 编译和字段清单自动生成。
6. 模板创建、复制、导入导出、发布、停用、默认绑定和版本预览兼容。
7. 全部启用审批类型 Provider 覆盖率测试。
8. 本地运行态、浏览器、HTML 和 PDF 一致性验收。
9. 分包计量完整详情字段、计量清单及真实业务数据预览。

### 2.2 非目标

1. 审批记录、审批节点、审批意见、签字流和附件字段。
2. 数据库列、实体、DTO 或任意对象反射生成字段目录。
3. JavaScript、外部资源、任意表达式和多层循环。
4. Office 模板、电子签章、邮件、批量异步生成。
5. 复制通用 ERP 表单引擎、工作流引擎或低代码平台。
6. 非本地环境测试、发布或生产操作。
7. 本计划不授权 commit、push、PR、合并、Tag 或 Release。

## 3. 核心不变量

1. 一个启用审批 `businessType` 必须对应且仅对应一个文档 Provider。
2. 字段目录和实际数据快照必须由同一个 Provider 提供。
3. Provider 复用既有领域详情 Service 及其租户、项目和对象访问检查。
4. 模板只消费显式登记的语义字段，不暴露租户 ID、删除标记、数据库外键等内部字段。
5. 集合字段只能在所属集合上下文中使用。
6. 字段清单由服务端从画布模型或受限 HTML 引用自动推导。
7. HTML 预览、PDF 校样和正式生成使用相同数据快照、模板编译器和渲染器。
8. 发布版本不可变；契约升级必须创建新模板版本。
9. 未配置 Provider 时返回明确失败，不使用 `business.*`、`workflow.*` 或 `approvalRecords.*` 兜底。
10. 金额、数量、状态和关联名称均来自既有业务事实，不在模板中重新计算。

## 4. 目标架构

### 4.1 Provider 契约

扩展现有 `DocumentDataProvider`：

```text
businessType()
displayName()
schemaVersion()
fieldCatalog()
sampleData()
loadPreview(businessId)
load(businessId)
```

字段元数据至少包含：

```text
path
label
valueType
nullable
group
collectionPath
masked
sortOrder
```

- `DocumentDataProviderRegistry` 继续负责 Provider 唯一注册和查找。
- `DocumentTemplateFieldCatalog` 改为 Provider 注册表门面，移除中央业务字段硬编码。
- Provider 不直接把实体、Mapper 结果或详情 DTO 暴露给模板。
- Provider 使用显式映射构建稳定快照，契约变化通过 `schemaVersion` 管理。

### 4.2 动态业务类型接口

新增：

```text
GET /document-templates/business-types
GET /document-templates/catalog?businessType={type}
```

业务类型响应包含：

```text
businessType
displayName
schemaVersion
providerReady
fieldCount
```

- 业务类型来源于服务端审批业务类型注册表，不再由模板页面维护静态枚举。
- 已存在审批类型但缺少 Provider 时返回 `providerReady=false`。
- `providerReady=false` 时模板页面禁止创建、编辑和发布，并显示“完整详情契约待配置”。
- `DEMO_APPROVAL_SCENARIO` 仅在本地演示配置启用时显示。

### 4.3 错误语义

| 错误码 | 含义 |
| --- | --- |
| `DOCUMENT_PROVIDER_UNAVAILABLE` | 当前审批业务类型未注册文档 Provider |
| `DOCUMENT_FIELD_UNAVAILABLE` | 模板引用字段不在完整详情契约中 |
| `DOCUMENT_FIELD_CONTEXT_INVALID` | 集合字段位于错误循环或表格上下文 |
| `DOCUMENT_SCHEMA_VERSION_MISMATCH` | 模板版本与业务数据契约版本不一致 |
| `DOCUMENT_DESIGN_SCHEMA_INVALID` | 画布模型结构、类型或约束无效 |
| `DOCUMENT_CANVAS_OVERFLOW` | 元素越出页面安全区域 |
| `DOCUMENT_TEMPLATE_COMPILE_FAILED` | 画布模型无法编译为受限 HTML |

## 5. 分包计量完整详情契约

`SUB_MEASURE / sub-measure.v1` 是首个参考实现。

### 5.1 主详情字段

| 分组 | 字段 |
| --- | --- |
| 基本信息 | 计量编号、计量期间、计量日期、项目名称、合同名称、分包单位、任务编号、任务名称 |
| 金额信息 | 报量金额、审定金额、扣款金额、净额 |
| 状态信息 | 审批状态、业务状态、成本生成状态 |
| 其他信息 | 备注、创建人、创建时间、更新时间 |

### 5.2 `items[]` 计量清单字段

1. 清单项名称。
2. 单位。
3. 合同数量。
4. 本期数量。
5. 累计数量。
6. 单价。
7. 金额。

### 5.3 数据装配约束

- 复用 `SubMeasureService.getById` 的租户、项目权限和业务详情读取逻辑。
- 创建人显示名称通过既有用户服务补齐，不向模板暴露用户 ID。
- 不暴露主键、租户 ID、项目/合同/分包商/任务外键或明细链接 ID。
- 金额和数量使用业务服务已形成的字符串精度，不使用浮点数或模板计算。
- 正式生成继续遵守分包计量业务状态和对象访问约束。

## 6. 数据与画布模型

### 6.1 数据迁移

在 `biz_document_template_version` 使用实施时下一可用 Flyway 版本新增：

```text
design_schema JSON NULL
```

- 同步提供 MySQL、H2 和 H2 legacy 测试迁移。
- 不修改任何已应用 migration。
- `design_schema=null` 表示旧源码模板，继续走现有渲染路径。
- 新字段不改变旧应用读取现有模板内容的行为。

### 6.2 画布模型

画布模型至少包含：

```text
page.size = A4
page.orientation = PORTRAIT | LANDSCAPE
page.marginMm
elements[]
tables[]
bindings[]
schemaVersion
```

- 坐标和尺寸统一使用毫米，不保存屏幕像素。
- 纵向固定 `210mm × 297mm`，横向固定 `297mm × 210mm`。
- 标量元素允许在安全区域内绝对定位。
- 集合数据使用可分页明细表，不允许逐行绝对定位。
- 页眉、页脚支持跨页重复。
- 切换方向不拉伸元素；越界元素高亮并阻止发布。

### 6.3 保存与编译

- 画布模板保存 `design_schema`。
- 服务端校验设计模型后生成现有 `template_content`。
- 服务端从绑定字段和表格列推导 `field_manifest`。
- 前端不再编辑字段清单 JSON。
- 复制、导入、导出和创建新版本同步携带画布模型。
- 发布后 `design_schema`、`template_content` 和 `field_manifest` 均不可变。

## 7. 前端交互契约

### 7.1 字段加载

1. 业务类型列表从服务端加载。
2. 选择类型后加载对应完整详情字段目录。
3. 字段按基本信息、金额、状态和业务明细分组。
4. 搜索同时匹配字段名称和路径。
5. 标量字段点击或拖拽后进入画布。
6. 集合字段只能进入所属明细表；首次使用集合字段时自动创建表格。
7. 删除字段或表格列后，字段清单同步删除；重复绑定只登记一次。

### 7.2 A4 设计与预览

- 方向按钮同时更新设计画布和实时 HTML 预览。
- 画布缩放只改变显示比例，不修改毫米坐标。
- 设计画布、HTML 预览和 PDF 使用同一页面配置。
- 实时预览可选择有权限的真实业务对象。
- 未选择业务对象时使用 Provider 定义的结构化示例数据。

### 7.3 重新打开

保存后重新打开必须恢复：

- 页面方向和边距。
- 元素位置、尺寸、字号、对齐和层级。
- 字段绑定。
- 明细表列、列宽和顺序。
- 页眉、正文、明细区和页脚配置。

## 8. 全审批类型覆盖

按领域分批实施，但正式完成要求全部启用审批类型 Provider 覆盖率达到 100%。

| 批次 | 业务范围 |
| --- | --- |
| A | 分包计量、采购申请、采购订单、材料验收、材料领用 |
| B | 合同审批、项目审批、合同变更、签证变更、开工、计划和进度纠偏 |
| C | 成本目标、项目预算、成本纠偏、成本科目映射、投标成本转入及冲销 |
| D | 付款、费用、结算、业主结算、合同收入、产值计量、财务费用分摊及冲销 |
| E | 技术事项、技术方案、竣工验收及其他启用审批业务 |

每种类型必须具备：

1. 完整语义详情字段清单。
2. 嵌套明细集合定义。
3. Provider 数据装配。
4. 对象访问权限。
5. 结构化示例数据。
6. 默认模板或明确“不提供默认模板”的登记。
7. 自动化测试和浏览器验收场景。

## 9. 权限与安全

1. 查询业务类型和字段目录需要模板查询权限。
2. 保存画布需要模板编辑权限。
3. 发布、停用和默认绑定继续使用现有分层权限。
4. 使用真实数据预览同时要求模板编辑、文档生成和业务对象访问权限。
5. Provider 必须执行租户、项目和业务对象访问检查。
6. 模板不得读取目录外字段或绕过脱敏标记。
7. 禁止脚本、外部样式、外部字体、任意 URL、任意表达式和实体反射。
8. 权限拒绝、对象不存在和状态不允许必须返回明确业务错误，不得静默使用示例数据。

## 13. 失败分类

所有测试、接口、页面、构建和运行态失败先按统一失败分类契约归类；未分类不得判为业务缺陷或修改产品逻辑。

| 分类 | 处理方式 |
| --- | --- |
| 产品缺陷 | 本轮修复并复验 |
| 测试缺陷 | 修复测试契约，不绕过业务校验 |
| 环境或运行态漂移 | 恢复本地事实后复跑 |
| 数据前置不足 | 补充受控本地演示数据 |
| 工具或命令错误 | 修正命令，不计入业务失败 |
| 超出范围 | 进入唯一正式载体，否则 G5 不通过 |

CI、PR 和运行态的具体失败分类以项目专项 Skill 为唯一权威，本计划不复制动态分类规则。

## 14. 风险与回滚

| 风险 | 预防与处理 |
| --- | --- |
| 字段遗漏 | Provider 覆盖测试同时验证目录和数据快照路径 |
| 目录与数据漂移 | 禁止中央目录与 Provider 双份维护 |
| 画布模型无法恢复 | 保存后立即回读并比较规范化设计模型 |
| 多页表格错位 | 集合表格使用流式分页，不允许逐行绝对定位 |
| 历史模板受损 | `design_schema` 可空，旧渲染路径保留 |
| 权限扩大 | 真实预览复用业务对象访问检查，拒绝时不回退示例数据 |
| 金额精度变化 | Provider 复用领域服务字符串精度，模板禁止金额计算 |
| 当前工作区冲突 | 第77条未收口前不得在当前脏工作区实施 |

1. 关闭画布入口，恢复旧源码编辑入口。
