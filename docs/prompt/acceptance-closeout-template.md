# 验收与上线裁决模板

用于主线程做阶段验收、收口结论或上线裁决。先写结论，再补证据，不写过程流水账。

```text
结论=通过 / 不通过
阻塞=非阻塞 / 阻塞
环境范围=本地开发环境
是否可上线=不适用（当前仅本地开发环境）

依据=
- 需求范围：
- 实际交付物：
- 验收证据：

验证命令=
- 

失败分类=
- 引用 .agents/skills/cgc-pms-ci-gate-triage/SKILL.md 的统一失败分类原值

剩余风险=
- 

回滚与跟踪=
- 回滚要求：
- 后续待办：
```

## 使用规则

- `通过/不通过` 与 `阻塞/非阻塞` 必须同时给出，不能只写其一。
- `验证命令` 只保留支撑结论的最小命令，不贴长日志。
- `失败分类` 只引用 [CI 门禁 Skill](../../.agents/skills/cgc-pms-ci-gate-triage/SKILL.md) 的七类原值，不在 Prompt 复制或另造分类。
- 当前项目仅有本地开发环境，`是否可上线` 固定为“不适用”；不得把非本地环境测试、验收或发布列为阻塞项。
