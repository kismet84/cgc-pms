## 2. 关键修复

### 2.1 认证与管理员连续性

- `SysUserService` 只允许更新白名单字段，禁止用户删除/停用自身，并以锁内启用管理员计数保护最后一个管理员。
- JWT 增加凭据版本；登录、刷新和请求过滤均按显式 `tenant_id + user_id` 查询当前密码摘要，避免认证前租户上下文默认值污染。
- 旧五参数测试令牌入口在可用数据库上下文中读取当前凭据；HTTP 控制器测试统一复用测试专用真实凭据令牌工厂，不在生产代码放宽校验。

### 2.2 系统管理与数据库权限

- 用户、角色、权限、字典、审计、业务单据模板和数据维护页面复用单一 V2 请求层与既有后端 API。
- 审计页面只查询，不提供修改或删除历史能力。
- `V234__register_operation_audit_permission.sql` 同步 MySQL/H2：注册 `/system/audit`、`audit:query`，仅绑定现有 `SUPER_ADMIN`，不改已应用迁移。

### 2.3 响应式与 Demo

- 移动端隐藏页头重复账号中心链接，账号中心仍保留在移动导航抽屉；390px 全局选择器宽度恢复门禁要求。
- Demo 加载对风险等级固定数据执行幂等恢复；验证器只裁决 `520000000000000000～520000000000999999` 包自有 ID，不把同租户外部业务数据误判为包数据。
