## 2. 服务端权威、权限与并发

- 资金运营与预测按租户、项目和当前用户可访问项目失败关闭；批量分析在各自租户事务内执行，不跨租户复用事务上下文。
- 资金账户和流水由服务端返回；归档、重开与冲销使用账户/流水锁、状态门禁和写后回读，附件必须属于当前业务对象且扫描状态为`CLEAN`。
- 预测写侧锁项目或预测版本后更新；实际收付来自资金日记账，不接受前端权威金额。
- 会计凭证复核、过账、驳回、重提和冲销锁定凭证并检查受影响行数；跨项目、非法状态、版本冲突、借贷不平失败关闭。
- 月结检查、关账、反结账、调整与银行回单写入均锁定期间；关账在锁内重新执行完整检查，银行回单统一使用`period → receipt`锁序，失败不留下部分期间状态或陈旧检查窗口。
- 预算操作幂等重放在权限校验后按操作类型、真实来源/目标预算行、合同额度和金额比对；原样重放返回同一操作且不二次改变余额，不同业务语义失败关闭。
- 资金运营、预测、凭证与月结V2接口使用稳定DTO；原始`Map<String,Object>`及`BigDecimal`未穿透到前端契约。
