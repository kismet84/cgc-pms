# 第57条主线支线C：第56条四类业务金丝雀任务计划书

**Goal:** 用四条最小端到端金丝雀证明第56条页面、权限、状态、金额、库存、审计与恢复路径可执行。

**Architecture:** 复用第56条独立环境、角色用户、账本和现有业务状态机；每类只创建一条链，写后立即服务端回读。禁止批量补齐、旧ID引用、跨链串号、绕过UI或为验收修改业务模型。

计划状态：`ACCEPTED / C0-C5_ACCEPTED`
阶段：`C0前置核验 → C1～C4单链金丝雀 → C5跨链验收`

## 1. 目标

在批量录入前，各完成一条施工总承包、专业分包、劳务分包和材料采购端到端业务链，证明页面、状态机、权限、金额、库存、审批和回滚机制可执行。

## 2. 执行规则

- 每类先执行一条。
- 每个对象提交后立即回读。
- 所有外键必须来自新对象账本。
- 下拉框只选择本轮对象。
- 自动编号由服务端生成。
- 首次失败必须分类。
- 未通过时不得补齐同类剩余数据。
- 任何代码修复后重新执行受影响金丝雀。
- 不复用修复前证据。

## 7. 每条金丝雀验收

### 权限

- 当前用户可访问目标项目。
- 申请人与审批人不同。
- 实际审批任务指派正确。
- 无越权按钮。
- 无跨租户数据。
- 无跨项目引用。

### 状态

- 草稿。
- 提交。
- 审批。
- 驳回或撤回代表性路径。
- 重提。
- 完成或归档。
- 非法状态动作被拒绝。

### 金额

- 合同金额。
- 预算金额。
- 目标成本。
- 计量。
- 结算。
- 付款。
- 发票。
- 现金。

累计关系必须守恒。

### 数量和库存

- 订单数量。
- 收货数量。
- 入库数量。
- 领料数量。
- 退料数量。
- 当前库存。
- 库存价值。

### 审计和追溯

- 创建人。
- 提交人。
- 审批人。
- 操作时间。
- 来源对象。
- 下游对象。
- 文件关系。
- 详情路由。

### 回滚

必须证明至少一种安全恢复方式：

- 草稿删除。
- 撤回。
- 作废。
- 冲销。
- 关闭。
- 独立链停止。

## 8. 失败处理

| 分类 | 处理 |
| --- | --- |
| 环境前置 | 恢复环境后复验 |
| 浏览器调用 | 刷新状态并修正一次 |
| 输入契约 | 修正账本或业务输入 |
| 权限/状态/金额/库存 | 建立缺陷稳定键并阻塞 |
| 缺入口 | 只读查证并决定是否属于真实缺陷 |
| 未知 | 暂停该链，不继续批量 |

## 10. 范围、非目标、风险与恢复矩阵

- 范围：施工总承包、专业分包、劳务分包和材料采购各一条新业务链。
- 非目标：不补齐剩余11个项目，不修改状态机、权限、金额或库存规则，不连接生产或旧业务数据。
- 风险：跨租户/跨项目引用、金额或库存失守、非法状态推进、错误审批人、写入后无法安全撤销。
- 失败分类：沿用第8节分类；权限、状态、金额、库存、租户和项目范围失败均阻塞对应金丝雀，未分类失败不得继续。

| 失败点 | 停止范围 | 恢复方式 | 复验起点 |
| --- | --- | --- | --- |
| 环境或登录前置 | 全部金丝雀 | 恢复独立环境并重新登录 | C0 |
| 单链输入或上游缺失 | 当前链 | 修正账本；不复用失败对象 | 当前对象前一步 |
| 权限、租户、状态、金额或库存 | 当前业务域 | 根因修复；使用撤回、作废、冲销或精确删除恢复 | 当前金丝雀起点 |
| 无安全回滚入口 | 当前类及其后续批次 | 保留证据并登记稳定键 | 暂停，等待裁决 |
