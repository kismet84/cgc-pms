# 阶段 8：并发、事务与幂等审计

## 已检查

工作流审批、付款、预算占用、现金日记、库存、文件生命周期、成本汇总、定时任务、重试与补偿。

## 证据

- 工作流使用行锁、CAS、任务版本和幂等键；并发审批和重复动作有测试。
- 付款来源额度、支付记录、预算预占/释放、现金入账与冲销均在事务边界内，并有 MySQL 并发测试定义。
- 现金账户、编号生成、材料删除和即时通讯包含行锁/唯一约束或并发测试。
- 文件对象与数据库记录使用任务表、重试和补偿处理跨资源失败。
- `FinanceOperations` 定时任务按租户使用独立事务并记录失败指标。

## 裁决

未发现可证实的重复付款、超额付款、重复审批或事务部分提交缺陷。`CostSummaryService` 的项目级 JVM 锁在当前单实例本地边界可用；若未来多实例部署，需要数据库锁或分布式互斥重新评估，本轮不登记为当前缺陷。
