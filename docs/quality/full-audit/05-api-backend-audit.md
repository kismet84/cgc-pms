## API-001：生成文档/派生预览错误回显底层消息（已修复）

- 等级/状态：原 P2，2026-08-20 本地整改复验通过。
- 证据：`FileService.java:761-792` 捕获 MinIO/客户端异常后拼接 `e.getMessage()`；普通文件入口 `FileService.java:232-238` 会再次统一为安全消息，但生成文档入口 `251-264` 与派生预览入口 `483-502` 未做同等包装；`GlobalExceptionHandler.java:55-65` 将 BusinessException 消息返回客户端。
- 触发：已授权用户请求生成文档或派生预览，且对象存储/公开 endpoint 配置触发异常。
- 影响：可能泄露对象存储主机、桶、对象路径或 SDK 诊断细节；不构成直接越权。
- 修复：统一所有 presign 公共入口为固定外部错误码/消息，完整异常仅写脱敏服务端日志。
- 验收：模拟包含内部 URI/桶名的 SDK 异常，HTTP 响应只含固定消息，日志保留 traceId 和内部栈且无凭据。

实现：`FileService.genPresignedUrl` 的所有调用方统一收到 `FILE_URL_ERROR/生成下载链接失败`，不再拼接 `Exception.getMessage()`。`FileServiceTest` 注入含内部 endpoint 和 secret 标识的异常，断言公开消息不包含内部文本；完整文件服务回归与后端全量验证通过。

其他已检查项：认证失败、资源隐藏、项目范围、分页、导出权限、金额序列化、文件权限、幂等键、失败分类。未发现其他可独立登记问题。
