# 阶段 4：数据库一致性审计

## 迁移与模型

- MySQL 活跃迁移 92 个，版本 215–307；H2 活跃迁移 82 个，版本 215–307；未发现同目录重复版本。
- 方言差异集中于 MySQL 专属能力，并由 baseline、fresh schema、upgrade 和 MySQL smoke 测试约束。
- 已应用迁移未被本轮修改；结构变化策略为新增版本化 migration。
- 业务金额未发现 `float`/`double` 存储；相关双精度使用集中于文档画布几何。
- 动态表 SQL 仅来自 `MandatoryAuditService` 私有常量，未接受用户表名。

## 一致性控制

租户字段、软删除、唯一键、乐观锁/行锁、审计事实、支付来源和现金日记关系均有源码或测试证据。CI 定义包含 MySQL 新建基线、升级、租户范围与并发测试。

## 限制与结论

本轮未重置数据库，也未对运行中数据库做写操作；实时数据量、真实约束分布和恢复后数据一致性属于待验证。源码与测试范围内未发现独立数据库风险。
