## 3. FLOW-001

Chromium用例使用项目经理、成本经理、部门经理、总经理、财务经办和独立财务复核六类真实角色：

1. 创建ACTIVE项目、含两个科目的ACTIVE预算、PERFORMING合同及合同预算分配。
2. 费用提交、证据上传和多级审批，只占用一次预算。
3. 付款申请驳回、修订、原实例重提到round 2；round 1记录保留。
4. 两次部分付款`60000.00 + 40000.00`；重复外部流水幂等返回同一PayRecord。
5. 两笔唯一PENDING_ARCHIVE日记分别上传银行回单并归档；预算由`100000.00 reserved / 0 consumed`转为`0 reserved / 100000.00 consumed`。
6. 一张`100000.00`发票分配到两笔付款；两张付款凭证由独立财务复核并过账，借贷相等。
7. 财务Dashboard对账：合同`600000.00`、实付`100000.00`、预算`1000000.00`、执行率`10`、现金流出`100000.00`；管理Dashboard项目实付一致。
8. 从第二笔现金日记返回项目、合同、费用、付款申请、审批、两笔付款、两笔日记、发票分配、预算台账和两张凭证。
9. 项目经理、财务、总经理分别可进入付款申请、现金日记和Dashboard页面，无403。
10. 同一真实角色脚本验证缺分类、预算不足、缺付款证据、DIRECT无权限、付款对象错链、重复提交、并发重复付款、重复归档、已分配发票删除、核验发票阻断冲销、已终止合同、暂停项目、跨项目及跨租户拒绝访问或写入。
